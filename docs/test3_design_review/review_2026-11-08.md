## The rules text that governs test 3

- **Test 3 (original):** "regress actual margin and total on nflverse's closing line plus the model's prediction, over 2018 to 2024. A model coefficient indistinguishable from zero means no information beyond the market."
- **Kill rule:** "If test 3 shows no added information, stop building features and pivot to the Kalshi-versus-close approach."
- **Discipline:** any change after seeing validation results is a new version. First-half markets are judged on score accuracy against simple baselines plus forward data, "since nflverse has no first-half lines".

- **Amendment 26 decision 11:** the walk-forward path is "the only model prediction test 3 uses", and "Test 3's claim is about this selection procedure, not about one fixed configuration."
- **Amendment 26 decision 12:** the final choice is not used in test 3.
- **Amendment 26 decision 16:** the error spread is not computed in test 2. A later result using strike probabilities is reported with and without 2018. Test 3 uses predicted margin and total, not strike probabilities, so decision 16 does not bind test 3 directly. Whether the with-and-without-2018 rule carries over is an open question (see topic 5).
- **Amendment 26 decision 17:** the SE "allows for no correlation between games in the same week or season". That is a known limit for test 2. Test 3 should decide this explicitly (see topic 3).
- **Features section:** nflverse lines "are hindsight values and are never model inputs. Lines are used only as a benchmark."

## 1. Closing line data

**Facts, read from the files**
- **File and columns:** data/historical/schedules/games.parquet (nflverse schedules) has `spread_line` and `total_line`, plus `result` (home minus away) and `total` (home plus away).
  - data/historical/derived/games.parquet has no line columns.
  - All 1,767 walk-forward game_ids match the schedules file 1:1 on game_id and season. All are game_type REG.
  - `result` = home_score − away_score and `total` = home_score + away_score hold in all 1,767 games.
- **Missing lines:** 0 missing `spread_line` and 0 missing `total_line` in every season, 2018 to 2024.
- **Sign convention:** positive `spread_line` means the home team is favored, i.e. it is the expected home margin. docs/data_sources.md states this, and these market-only checks on the 1,767 games agree:
  - Slope of `result` on `spread_line`: 1.0115, intercept −0.1427.
  - Correlation: 0.4388.
  - The side `spread_line` favors won 65.82% of the 1,767 games. No line is 0.
  - Mean `spread_line` is +1.68 and 60.8% are positive, consistent with home field.
  - When `spread_line` > 0, the home moneyline is negative in 98.08% of games. About 34 games have a positive spread and a non-negative home moneyline, or the reverse. These are probably near pick'em, but this was not checked.
- **Closing or not:** nothing in the repo shows these are closing lines.
  - docs/data_sources.md section 3: "Lines … are overwritten as they move … For past games the value is the last one nflverse captured. When that capture happened, and whether it is the true close, is **unknown**."
  - Section 5 lists it again as unverified.
  - **Unverified:** that `spread_line`/`total_line` are closing lines, and from which book or consensus.
- **Other market facts:**
  - Pushes against the line: 46 margin, 20 total.
  - Standard deviations: `spread_line` 6.2244, `total_line` 4.5511.
  - 33 team codes appear, presumably because OAK became LV in 2020. Not checked.

**Ambiguities**
- (1a) Whether "nflverse's closing line" may be read as "nflverse's last captured line" when closing is unverified.
- (1b) Whether the moneylines and spread odds (vig) are used. They would let the line be adjusted for juice. The original text names only the line.
- (1c) The source and book behind the line are unknown.

**Options**
- **A. Use `spread_line`/`total_line` as they are, and record "closing" as an unverified assumption with a known limit.**
  - If the value is a later or better line than the true close, the test is only harder for the model.
  - If it is earlier, the market benchmark is weaker and the test easier.
- **B. Verify against an outside closing-line source first**, for example a public archive.
  - This needs the network and a new data source.
  - It delays test 3 and adds a dependency the rules never named.
- **C. Adjust the line for vig using the moneylines.**
  - More precise, but it adds a modelling choice not in the original text, and it uses columns of uncertain timing.

**Recommendation: A.**
- The original text names nflverse's line, and it is complete for all 1,767 games.
- The direction of the risk is stated: a line captured late, if anything, carries more information than the close.
- Record the closing-line assumption as unverified in the amendment, as data_sources.md already does.
- Don't use moneylines or odds.

## 2. The regression

**Definitions:** predicted margin m̂ = pred_home − pred_away, and predicted total t̂ = pred_home + pred_away, from walk_forward.parquet. The line is L: `spread_line` for margin and `total_line` for total. The actual value is y: `result` or `total`.

**Ambiguities**
- (2a) Whether the line's coefficient is free or fixed at 1.
- (2b) Whether there is an intercept.
- (2c) Which coefficient is the test, and its null value.
- (2d) Whether margin and total each get their own regression with only their own variables, or whether total enters the margin equation and the reverse.

**Options**
- **A. Encompassing regression, as the text reads:** y = a + b·L + c·model + e. The test is on c, and c = 0 means no information beyond the line.
  - Matches the original wording literally.
  - b is free, so a line that is mis-scaled cannot be credited to the model.
  - If m̂ and L are highly correlated, SE(c) grows, because only the part of the model independent of the line identifies c.
- **B. Constrained form:** (y − L) = a + c·(model − L) + e. The test is on c, and c = 0 means no information. This imposes b = 1 − c.
  - One regressor, easy to read: c is the weight on the model in a blend of the line and the model.
  - If the line's own coefficient is not 1 − c, the model can be credited with correcting the line's scale. This is a mild risk, since the market-only slope of result on spread_line is 1.0115.
- **C. Fair–Shiller form without an intercept:** like B with a = 0.
  - Slightly more power.
  - Any home-field or league-wide bias in the line is then credited to the model. Rejected.

**Recommendation: A, with an intercept, one regression per market with only that market's own line and model value. c is the test coefficient and c = 0 is the null.**
- A is what the frozen text says ("regress actual … on … closing line plus the model's prediction").
- A is the more conservative of A and B.
- Report B's c as a secondary, descriptive number only.

## 3. Significance

**Ambiguities**
- (3a) The test statistic and level.
- (3b) One-sided or two-sided.
- (3c) How the SE is computed.
- (3d) Small-cluster corrections.

**Options for the side**
- **One-sided (H1: c > 0).** A model with information should get positive weight, and c < 0 counts as "no added information" under the kill rule. More power for the same level.
- **Two-sided.** The conventional choice, but a significantly negative c would "show information" by the letter of the rule, which makes no sense for a forecast.

**Options for the SE** (cluster counts from the 1,767 games):
- **Plain OLS:** 1,767 independent observations. It ignores within-week and within-season correlation, which Amendment 26 decision 17 flags.
- **Heteroskedasticity-robust (HC1):** same independence assumption. It handles unequal variance.
- **Clustered by season-week:** **123 clusters**.
  - Seasons have 17 weeks in 2018 to 2020 and 18 in 2021 to 2024.
  - Each cluster has 5 to 16 games, median 14.
  - That is enough clusters for the usual cluster-robust SE, with t(122) critical values.
- **Clustered by season:** **7 clusters**.
  - Cluster-robust SEs are unreliable with 7 clusters. They need a small-sample correction such as CR2 or a wild cluster bootstrap, plus t(6) critical values (one-sided 5%: 1.943; one-sided 2.5%: 2.447).
  - This roughly halves the power.
- **Team-level dependence:** each team plays about 17 games a season, which no one-way clustering here captures. Two-way clustering (week × team) is possible but adds complexity.

**Recommendation**
- Test with a t-test on c, one-sided (H1: c > 0).
- Use cluster-robust SEs by season-week (123 clusters, CR1 with t(122) critical values).
- Report plain, HC1 and season-clustered SEs as descriptive sensitivities that decide nothing.
- Set the level under topic 4: one-sided 2.5% per market if the two are judged separately with a Bonferroni split, otherwise one-sided 5%.

Why:
- Season-week clustering answers Amendment 26 decision 17's known limit directly and still leaves enough clusters.
- Season clustering with 7 clusters is too fragile to decide the kill rule on.
- Fix all of this before any test 3 number exists.

**Software note:** .venv has no statsmodels, scipy or scikit-learn, and /usr/bin/python3 has no pandas or numpy. OLS with cluster-robust SE is a few lines of numpy. t critical values need either a hard-coded table or a small t-distribution routine.
- The memory rule forbids installing into .venv.
- The amendment should state that the code computes these by hand, and the tests should check them against values computed by hand on synthetic data.

## 4. Margin and total

**Ambiguities**
- (4a) Whether margin and total are judged separately or jointly.
- (4b) What a split result means for the kill rule ("stop building features").
- (4c) The level when there are two tests.

**Options**
- **A. Separately, and the kill rule fires only if both fail. Bonferroni at one-sided 2.5% each.**
  - Family-wise false "information" rate of at most 5%.
  - On a split, building continues, and the failing market is recorded as having no added information. Tests 5 and 6 would treat that market by the Kalshi-versus-close approach only.
  - Costs some power per market.
- **B. Separately, and the kill rule fires if either fails** (both must pass), each at one-sided 5%.
  - Strictest for continuing.
  - Kills the project if one market shows no information while the other does. That throws away a working market, and the rule's wording ("no added information") does not require it.
- **C. One joint test (Wald or F) of c_margin = c_total = 0**, from a stacked system with clustered covariance.
  - One decision and the most power when both carry a little information.
  - Passes even when all the information is in one market and says nothing about which one. It is harder to code and to explain.

**Recommendation: A.**
- The kill rule says "no added information", which is naturally read as information in neither market.
- Bonferroni keeps the overall error rate at 5% without a joint covariance model.
- The amendment should state what a split means for later tests: the failing market gets no model-based trading in tests 5 to 7, unless a later amendment written before those tests says otherwise.

## 6. Selection bias

**How far walk-forward selection answers it**
- Each season T's configuration was chosen using only seasons before T (Amendment 26 decision 11). So no season's prediction was chosen by looking at that season's outcomes.
- The final choice, which did see all of 2018 to 2024, is excluded from test 3 (Amendment 26 decision 12).
- Penalty tuning used 2014 to 2017 and the carry factors 2010 to 2017 (Amendments 22 and 24). Neither touched the test seasons.

**Remaining known limits**
- (6a) **The grid and features were designed by people who knew NFL history through 2024.** The feature list, the grid values (lookback 3, 5, 8; half-life 4, 8, 16; F 4, 8, 12) and the ablation ladder were frozen before any result. They were not frozen before anyone had seen those seasons played. This cannot be removed. It is the usual limit of any backtest on past seasons.
- (6b) **Test 2's errors on 2018 to 2024 are now known** (Amendment 37 decision 4). Choosing test 3's regression form, SE or level after that could be steered. That is why every test 3 choice should be fixed by amendment before any test 3 number exists. These test 2 errors do not combine the model with the line, so they show nothing about c.
- (6c) **Amendment 37 known limit (a).** Half-life 16, F 12 and lookback 8 sit at the tops of their grids. Test 3 inherits a grid that may be too short. Extending it now would be selection on the test seasons, so it is not done.
- (6d) **The 2019 and 2020 choices rest on one or two seasons** (Amendment 26 decision 11; Amendment 37 decision 9(c)).
- (6e) **Test 3's claim is about the procedure, not one fixed configuration.** A pass does not certify the final choice used for 2025. The 2025 holdout (test 6) is the only clean test of it.

**Recommendation:** state 6a to 6e as known limits in the test 3 amendment, and settle every test 3 choice before running it.

## 7. Power (market statistics only)

**Inputs (actual minus line, 1,767 games)**
- **Margin, result − spread_line:** mean −0.1234, SD 12.8927. By season: 13.241, 13.119, 12.613, 13.648, 11.691, 13.138 and 12.611.
- **Total, total − total_line:** mean 0.5243, SD 13.1735. By season: 13.569, 13.466, 12.734, 13.332, 13.216, 13.242 and 12.611.

**Approximation**
- The residual SD of either regression is at most these SDs. Adding regressors can only lower it.
- SE(c) ≈ σ / (√n · s), where n = 1,767 (√n = 42.04) and s is the SD of the model's part independent of the line: model − line in option B, or the residual of the model on the line in option A.
- **s cannot be computed here without a model prediction, so it is left as a parameter.**
- The minimum detectable c at 80% power is about (z_α + 0.84) · SE:
  - one-sided 2.5%: 2.80 · SE
  - one-sided 5%: 2.49 · SE
- Plain SEs are assumed. Clustering by week would raise them somewhat, by an unknown design effect. Clustering by season with t(6) would raise the multiplier to about 3.35 at one-sided 2.5%.

| s (points) | SE(c), margin | MDE margin, 1-sided 2.5% | MDE margin, 1-sided 5% | SE(c), total | MDE total, 1-sided 2.5% | MDE total, 1-sided 5% |
|---:|---:|---:|---:|---:|---:|---:|
| 0.5 | 0.613 | 1.72 | 1.53 | 0.627 | 1.75 | 1.56 |
| 1.0 | 0.307 | 0.86 | 0.76 | 0.313 | 0.88 | 0.78 |
| 1.5 | 0.204 | 0.57 | 0.51 | 0.209 | 0.59 | 0.52 |
| 2.0 | 0.153 | 0.43 | 0.38 | 0.157 | 0.44 | 0.39 |
| 3.0 | 0.102 | 0.29 | 0.25 | 0.104 | 0.29 | 0.26 |

**Reading:**
- If the model's independent variation is 1 to 2 points, as is typical when a model is close to the market, only a weight of about 0.4 to 0.9 on the model is detectable with good power.
- A model with real but modest information (c around 0.1 to 0.3) would most likely be judged "indistinguishable from zero".
- Under the kill rule as written, an underpowered test therefore leans toward killing. The amendment should state this asymmetry as a known limit.
- A possible addition, descriptive only: report the confidence interval for c, so that "no evidence" and "evidence of none" can be told apart.
- s itself is a model prediction quantity. It is known only once test 3 runs, so this power statement cannot be made exact beforehand.

## 9. Other ambiguities to settle by amendment before test 3 code

1. **What "pivot to the Kalshi-versus-close approach" means in practice.** Which tests still run if the kill rule fires: test 5 (baseline) presumably, test 4 (ceilings) possibly not, and tests 6 and 7 with what model, if any. Also whether "stop building features" freezes the current model or drops it.
2. **What a pass permits.** Whether a pass in one or both markets is a gate for tests 4 to 7, and whether a pass carries any condition on the size of c.
3. **Information set mismatch.** The model uses information known at the cutoff (8pm ET two days before the game). The nflverse line is captured at an unknown, probably later time, with later injury news. That makes test 3 conservative for the model. Record it as a known limit, and don't adjust for it.
4. **Within-team dependence across weeks** is not captured by season-week clustering (topic 3). Record it as a known limit, or choose two-way clustering.
5. **The mean of actual minus line** (margin −0.1234, total +0.5243) is absorbed by the intercept in options A and B. Confirm that the intercept is not tested and decides nothing.
6. **Multicollinearity in option A.** If corr(m̂, spread_line) is very high, b and c are individually imprecise. The amendment should say the decision uses c's t statistic only, whatever b is, and that b is reported but not tested.
7. **Outliers and blowouts.** No winsorizing or trimming, to match test 2's unclipped treatment. State it.
8. **Whether a descriptive "blend" result is reported:** the out-of-sample error of line versus line-plus-model, for example by leave-one-season-out. It could be reported as information only, but it is a new number that could invite post-hoc reading. Recommend not reporting it, or fixing it in advance as descriptive only.
9. **The moneyline/spread inconsistency** in about 34 games (topic 1) is noted but does not touch `spread_line`. No action unless the amendment uses moneylines.
10. **Wording for the result.** Test 3's result should be recorded as "information beyond nflverse's last captured line", given the unverified close (topic 1).
11. **Open questions this closes:** the original "Indistinguishable from zero (test 3)" ambiguity, and Amendment 12's "test 3 significance". A test 3 amendment should list them as settled.
